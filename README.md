# Prehistoric Run

Build a complete, polished, premium-quality desktop browser game inspired by the classic offline dinosaur runner, but with a completely original visual identity.

TECHNOLOGY:



React, Vue, TypeScript, Three.js, Phaser, PixiJS, or other libraries/frameworks may be fully allowed.

Choose the technology that provides the best visual quality and browser performance.

The final game must run directly in a modern desktop browser.

GAMEPLAY:

Endless side-scrolling dinosaur runner.

Smooth jump, duck, acceleration, landing, and collision physics.

Procedurally generated obstacles.

Difficulty and game speed progressively increase.

Dynamic scoring, distance counter, high score, and best run.

Game-over screen with restart functionality.

Pause/resume system.

Keyboard controls:

Space / Arrow Up = Jump

Arrow Down = Duck

P = Pause

Smooth 60 FPS gameplay.

VISUAL QUALITY:
Create a highly polished, realistic game rather than a basic Chrome Dino clone.

Realistic detailed dinosaur character.

High-quality running, jumping, landing, and ducking animations.

Cinematic prehistoric environment.

Detailed ground, rocks, vegetation, trees, mountains, clouds, fog, dust and atmospheric effects.

Dynamic lighting and shadows.

Parallax background layers.

Particle effects for dust, footsteps, impacts and environmental effects.

Smooth camera movement and subtle screen shake.

Multiple prehistoric environments/biomes that transition during gameplay.

Premium cinematic presentation while remaining lightweight enough for browser performance.

UI:

Minimal professional desktop-game interface.

Clean HUD displaying score, distance, speed and best score.

Elegant pause button.

Professional start screen.

Cinematic game-over screen.

Smooth transitions and micro-animations.

Modern typography and subtle glass-style interface elements.

Do NOT copy Chrome Dino's exact UI, graphics, assets, colors or branding.

AUDIO:

Add background ambience.

Dinosaur footsteps.

Jump and landing sounds.

Obstacle interaction sounds.

UI click sounds.

Environmental sounds such as wind and birds.

Optional background music.

Add mute/unmute controls.

Audio should respond naturally to gameplay events.

PERFORMANCE:

Optimize everything for modern desktop browsers.

Target stable 60 FPS.

Use efficient rendering, object pooling and asset management where appropriate.

Avoid unnecessary DOM operations.

Keep memory usage low.

Make the game responsive to different desktop resolutions.

Include loading and asset fallback handling.

IMPORTANT:
The result must be a COMPLETE PLAYABLE GAME, not a mockup or prototype.

Do not simply reproduce the original Chrome Dino game. Create an advanced, visually impressive, original prehistoric endless runner that demonstrates the maximum quality possible inside a browser.

```sh
git clone <this-repository-url>
cd <repository-name>

```
